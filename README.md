# 🛠️ HelperTool - Инструкция по использованию

Добро пожаловать в HelperTool! Эта программа создана для облегчения работы модераторов на серверах Cristalix.

## 🚀 Первый запуск

### Авторизация через Google
При первом запуске программы потребуется войти в систему через ваш Google-аккаунт. Этот шаг необходим для проверки лицензии и загрузки требуемых данных.

**Важно:** Так как HelperTool является неофициальным приложением, Google может показать предупреждение о непроверенном разработчике. Это стандартная процедура - просто продолжите авторизацию.

После успешной авторизации будет создан файл `token.json` с вашими данными для входа. **Не удаляйте этот файл** - он необходим для корректной работы программы.

## ⚙️ Настройка программы

### Настройка Telegram бота

1. **Создание бота:**
   - Перейдите к [@BotFather](https://t.me/BotFather) в Telegram
   - Используйте команду `/newbot`
   - Задайте название бота (на любом языке)
   - Задайте username бота (только латиница, должен заканчиваться на `bot` или `Bot`)

2. **Получение токена:**
   - После создания бота BotFather предоставит вам уникальный токен
   - Скопируйте этот токен в формате `число:строка`

3. **Получение Chat ID:**
   - **Способ 1:** Перейдите к [@RawDataBot](https://t.me/RawDataBot) - он покажет полные данные вашего аккаунта, включая ID
   - **Способ 2:** Используйте [@chatIDrobot](https://t.me/chatIDrobot) - специализированный бот для получения ID
   **ЕСТЬ ЕЩЕ СПОСОБЫ, ЭТИ ПРЕДСТАВЛЕНЫ ДЛЯ ПРИМЕРА, КАК ПОЛУЧИТЬ ВАШ Chat ID**

### Настройка ВК бота
   - Перейдите по ссылке на бота: https://vk.com/crihelpertool
   - Войдите в личные сообщения с группой
   - Нажмите кнопку «Начать»
   - ГОТОВО!!!

### Получение VK ID:

1. **Если у вас короткая ссылка**
   - Зайдите в Настройки (шестеренка)
   - Раздел «Общее» → «Короткое имя»
   - Нажмите «Редактировать» — под полем ввода высветится надпись «Ссылка будет выглядеть как vk.com/id12345». Это и есть ваш VK ID (цифры, после id)

2. **Если у вас обычная ссылка**
   - Зайдите в свой профиль
   - Посмотрите на адресную строку браузера
   - Цифры после vk.com/id — это ваш ID

### Настройка в программе

В окне настройки заполните следующие поля:

- **Никнейм** - ваш игровой никнейм на Cristalix

- **Клиент** - выберите один из вариантов:
  - `Minigames` - для основного клиента (стандартный путь: `C:\Users\Имя_пользователя\.cristalix\updates\Minigames\logs\latest.log`)
  - `Staff Minigames` - для staff-клиента (стандартный путь: `C:\Users\Имя_пользователя\.cristalix\updates\Minigames-staging-java21\logs\latest.log`)
  - `Свой путь` - **для пользователей с нестандартной установкой Cristalix**
    *При выборе этого варианта появится поле для ввода пути и кнопка "Обзор" для выбора файла `latest.log` вручную*

- **Платформа** - выберите один из вариантов:
  - `Telegram` - для отправки в телеграм
  - `ВКонтакте` - для отправки в ВК

- **Token Bot** - вставьте токен вашего бота в TG (только для Telegram)
- **Chat ID** - вставьте ваш цифровой ID (полученный одним из способов выше) в TG (только для Telegram)
- **VK ID** - вставьте ваш цифровой ID в VK (только для ВКонтакте)

- **Kd скрина** - задержка между открытием чата и скриншотом (ползунком можно выбрать от 0.1 до 1.0 секунды)

- **Звуковые уведомления** - отметьте галочкой для включения звуков

**Важно:** При первой проверке настроек программа отправит тестовое сообщение для подтверждения корректности данных.

## 🎯 Как работает программа

### Основные функции:
- **Автоматический мониторинг** логов игры
- **Отправка уведомлений** в Telegram о выданных наказаниях
- **Создание скриншотов** по горячей клавише
- **Статистика** вашей модераторской активности

## 📊 Интерфейс программы

После запуска вы увидите:
- **Панель статистики** - количество выданных мутов, варнов и киков за сессию
- **Таймер сессии** - время работы программы
- **Лог действий** - все события и логи с сервера
- **Кнопки управления** - настройки и функции

### Режимы отображения логов

В правом верхнем углу окна находится кнопка переключения режима отображения новых сообщений в логе:

- **Все логи** - отображаются **все** игровые события: системные сообщения, подключения/отключения игроков, спавн мобов, действия с мирами и т.д. Полезно для полного контроля происходящего на сервере.

- **Только чат** - отображаются **только** сообщения из игрового чата (с пометкой `[CHAT]`) и системные сообщения самой программы. Удобно, когда нужно следить только за общением игроков, игнорируя технические сообщения сервера.

Выбранный режим автоматически сохраняется и восстанавливается при следующем запуске программы.

## ❗ Важные примечания

- Программа может быть запущена **как до, так и во время** игры - она автоматически начнет отслеживать логи, как только они появятся
- Убедитесь, что выбрали правильный путь к логам в зависимости от используемого клиента
- Если у вас **нестандартный путь установки Cristalix** (другой диск, кастомная папка), обязательно используйте опцию **"Свой путь"** и укажите расположение файла `latest.log` вручную
- При изменении ника основного аккаунта, вставьте измененный никнейм в поле вашего никнейма на этапе **Настройка конфигурации**
- Регулярно обновляйте программу для получения новых функций

## 🔧 Устранение неполадок

### Программа не видит логи
1. Проверьте правильность выбранного клиента (Minigames / Staff Minigames)
2. Если у вас нестандартная установка Cristalix, используйте опцию **"Свой путь"** и укажите путь вручную через кнопку **"Обзор"**
3. Убедитесь, что игра запущена и логи пишутся

### Не приходят уведомления о наказаниях
1. Проверьте, что программа запущена
2. Убедитесь, что в логах отображаются ваши действия
3. Проверьте настройки платформы (токен/ID)
