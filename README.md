# HelperTool

Программа для модераторов Cristalix: следит за логом, отправляет наказания и делает скриншоты по горячей клавише.

## Первый запуск

Нужен интернет: уведомления уходят через него.

Настройка, загрузка и главная панель открываются в одном окне. Окно можно растягивать за края.

Настройки хранятся в `%APPDATA%\HelperTool\helpertool.db` (Windows) или `~/HelperTool/helpertool.db` (Linux и macOS). Скриншоты лежат в подпапке `screenshots`. Если остались старые файлы `config.yml`, `theme.txt` и `binds.txt`, программа один раз переносит их в базу.

## Настройка

### Telegram

1. Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Скопируйте токен в формате `число:строка` в поле **Token Bot**.
3. Узнайте свой числовой id, например через [@RawDataBot](https://t.me/RawDataBot) или [@chatIDrobot](https://t.me/chatIDrobot), и вставьте его в поле **TG ID**.

### ВКонтакте

1. Откройте https://vk.com/crihelpertool и нажмите «Начать» в сообщениях группы.
2. Ваш VK ID — цифры в адресе профиля после `vk.com/id`. Если стоит короткое имя, откройте Настройки → Общее → Короткое имя → Редактировать: под полем будет ссылка вида `vk.com/id12345`.

### Поля в программе

- **Никнейм** — ваш игровой ник на Cristalix. Если ник сменился, укажите новый, иначе программа не узнает ваши наказания.
- **Клиент**
  - `Minigames` — `C:\Users\Имя\.cristalix\updates\Minigames\logs\latest.log`
  - `Staff Minigames` — `C:\Users\Имя\.cristalix\updates\Minigames-staging-java21\logs\latest.log`
  - `Свой путь` — если Cristalix стоит в другой папке. Появится поле и кнопка обзора для `latest.log`.
- **Платформа** — Telegram или ВКонтакте.
- **Kd скрина** — пауза между открытием чата и скриншотом, от 0.1 до 1.0 секунды.
- **Звуковые уведомления** — звук при муте и варне.

При первой проверке Telegram программа отправит тестовое сообщение.

## Главная панель

- Счётчики мутов, варнов и киков за эту сессию.
- Таймер сессии.
- Лог. Кнопка **Все логи** показывает все строки игры. **Только чат** оставляет чат и сообщения самой программы. Выбор сохраняется.
- Кнопка **Тема**: Dark Orange, Dark Blue, Light White, Purple.
- **Изменить бинд скриншота** — нажмите кнопку и затем клавишу. Одно нажатие даёт один скриншот.
- Если вышла новая версия, в заголовке появляется кнопка обновления.

Программу можно запустить до игры: она начнёт читать лог, когда файл появится.

## Если что-то не работает

Лог не читается: проверьте клиент или укажите свой путь к `latest.log`. Игра должна быть запущена, чтобы лог писался.

Уведомление не пришло: программа должна быть запущена, в логе должно быть видно ваше наказание, а токен, TG ID или VK ID должны быть верными.
